# Surakshit Nidhi 

**Surakshit Nidhi** is a centralized, AI-augmented, tamper-evident regulatory platform engineered to govern the complete 10-year administrative lifecycle of security deposits and Fixed Deposit Receipts (FDRs) submitted by **~10,000+ technical institutions** under the AICTE Approval Process Handbook (APH 2024–27 & 2026–27 Addendum).
